# Release v1.101.3

## Summary

v1.101.3 ships unified sidebar section composition for WorkQueue and AgentPanel, and replaces the always-on daemon workspace-list subscription with watch-gated inbox nudges plus safety reconciliation. Phase 1 aligns workspace recency with `OBSERVATION_TTL_MS` (60s); Phase 2 removes the live Convex subscription entirely.

**Current release branch state:** 1 commit (version bump only). **Proposed scope** from in-flight PRs: **28 files changed** (+339 / −302) across **14 commits** (#1542–#1545 stacks). Merge to `release/v1.101.3` pending user approval.

## Themes

### 1. WorkQueue sidebar UX unification (#1542 → #1543)

| PR    | Scope                                                                                                                                                         |
| ----- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| #1542 | Static WorkQueue sidebar sections — always-visible Current/Queued/Pending Review/Backlog with consistent headers, empty states, max-three previews, View More |
| #1543 | Composable `SidebarSection` primitives; migrate WorkQueue and AgentPanel to shared layer                                                                      |

**Outcome:** WorkQueue and AgentPanel share a composable `SidebarSection` primitive (`Root`, `Header`, `Toolbar`, `Body`, `Empty`, `Loading`, `Subheader`, `ViewMore`) with `SIDEBAR_PREVIEW_LIMIT = 3`. WorkQueue sections are always visible with static empty states instead of collapsing when empty. `WorkQueueSection.tsx` is removed in favor of `sidebar/SidebarSection.tsx`. `ViewMoreButton` moves to `sidebar/`.

**Key files:**

### 2. Watch-gated workspace sync — Phase 1 (#1544)

| PR    | Scope                                                                                       |
| ----- | ------------------------------------------------------------------------------------------- |
| #1544 | Align workspace-list recency default with `OBSERVATION_TTL_MS` (60s) across backend and CLI |

**Outcome:** Idle workspaces leave daemon sync scope after frontend observation heartbeats expire (60s window, matching `FRONTEND_OBSERVATION_HEARTBEAT_MS` at 45s). Explicit on-demand git sync behavior unchanged. `WORKSPACE_LIST_RECONCILE_MS` documented at 1 hour for TTL drift fallback.

**Key files:**

### 3. Watch-gated workspace sync — Phase 2 (#1545)

| PR    | Scope                                                                                  |
| ----- | -------------------------------------------------------------------------------------- |
| #1545 | Remove always-on workspace-list subscription; inbox nudges + imperative reconciliation |

**Outcome:** `workspaces.listRecentlyObservedWorkspacesForMachine` live subscription removed from daemon subscriber registry. Backend enqueues `daemon.workspaceListChanged` machine commands on workspace membership changes and watch-start/refresh. Daemon reconciles workspace list imperatively via `reconcileWorkspaceList` on inbox nudge; safety polling covers TTL drift. Addresses bandwidth finding #1 in `memory/architecture/bandwidth-at-rest-scaling.md` (203 MB prod / 191 MB dev).

**Key files:**

- `services/backend/src/domain/usecase/workspace/enqueue-workspace-list-changed.ts` (new)
- `services/backend/src/domain/entities/machine-command.ts` — `daemon.workspaceListChanged` command type
- `packages/cli/src/daemon/entry/command-dispatch.ts` — dispatch handler
- `packages/cli/src/daemon/infrastructure/convex/subscribers/workspace-list.ts` (deleted)
- `services/backend/tests/integration/workspace-list-changed-inbox.spec.ts` (new)

## Behavioral changes (user-visible)

- **WorkQueue sidebar:** All four work sections (Current, Queued, Pending Review, Backlog) always visible with consistent icon/title/count headers and empty-state messaging.
- **AgentPanel sidebar:** Uses same section styling and preview limits as WorkQueue.
- **Daemon bandwidth:** Workspace-list Convex subscription no longer runs continuously; daemon sync scope driven by observation TTL and inbox nudges.
- **Git sync scope:** Workspaces drop from daemon sync lists ~60s after frontend stops observing their chatroom.
